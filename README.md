# dCrosshair

Desktop application for gamers to create custom crosshairs in games where built-in crosshairs are not available.

---

## Features

* Select and manage multiple crosshair profiles
* Customize crosshair color, type, and size
* Real-time preview overlay on your screen
* Save and load profiles for quick switching

---

## Installation

1. Clone the repository or download the source code.
2. Install required Python modules:

```bash
pip install -r req.txt
```

---

## Usage

Run the application with Python:

```bash
python crosshair.py
```

* Open the **dCrosshair Library** window to customize your crosshair.
* Select a profile or create a new one.
* Adjust color, size, and type.
* Save your changes to keep your configuration.

---

## Supported Crosshair Types

* Dot
* Crosshair
* X-Crosshair

---

## Notes

* The overlay works on top of your screen, so make sure the app is running while playing.
* Profiles save all settings including color, size, type, and opacity.
